# VelociCalc-LO
VelociCalc LO es una plataforma digital especializada en el cálculo y estimación técnica de velocidades vehiculares para la investigación y reconstrucción de accidentes de tránsito, mediante fórmulas físico-matemáticas que consideran huellas de frenado, derrapes, coeficientes de fricción, pendientes y condiciones de la superficie vial.
